# AERIVA — Underarm Reset Cream

Static React + Vite landing page based on the supplied AERIVA MVP website specification.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Notes
- Static frontend only.
- No backend, authentication, database, payment, or real e-commerce.
- Google Form is represented by a placeholder until a real URL is supplied.
- Product, ingredient percentages, pricing and claims are presented as MVP/product-development concepts.
